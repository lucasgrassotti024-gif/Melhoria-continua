# Plataforma Lean Six Sigma — Melhoria Contínua (DMAIC)

Plataforma profissional de aplicação prática de ferramentas Lean Six Sigma para projetos de melhoria contínua baseados no ciclo DMAIC.

## 🎯 Objetivo
Ambiente de trabalho corporativo para profissionais Green Belt e Black Belt estruturarem, analisarem, acompanharem e documentarem seus projetos de melhoria.

## 🛠️ Estrutura DMAIC
- **DEFINE:** Project Charter, SIPOC, Voice of Customer (VOC), Árvore CTQ, 5W2H e Matriz de Stakeholders.
- **MEASURE:** Central de ingestão de dados (Excel/CSV/Paste), Estatística Descritiva, Histogramas, Diagrama de Pareto, Boxplot, Análise de Capacidade ($C_p, C_{pk}$) e MSA (Gage R&R).
- **ANALYZE:** Diagrama de Ishikawa (6M/Personalizado), 5 Porquês, Matriz Causa e Efeito, FMEA e Testes Estatísticos (ANOVA, Regressão, Correlação).
- **IMPROVE:** Brainstorming de Soluções, Matriz Esforço x Impacto, Matriz de Priorização, Planos de Ação 5W2H, Testes Piloto e Calculadora de ROI / Payback.
- **CONTROL:** Plano de Controle Operacional, Cartas de Controle Estatístico (SPC), Comparador Antes x Depois, Dashboard de Indicadores e Relatório Final Executivo.

## 🚀 Tecnologias
- **Frontend:** React, TypeScript, Vite, Tailwind CSS, Lucide Icons.
- **Componentes:** Radix UI / Primitivos acessíveis.
- **Backend / Infra:** Firebase (Auth, Firestore, Storage).
